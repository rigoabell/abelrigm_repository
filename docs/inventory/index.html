Inventory

Warehouse Inventory Desk

Open a current-inventory CSV. Average Age and Average Threshold are the ASIN’s age and threshold. Approaching is 1–2 days before the threshold, At is less than 1 day before it, and DIOT is past it. The inventory threshold is 0.5% of the site’s total units, and every DIOT count shows how far those units sit from it. A saved copy is stored in this public repository, so the same file opens on any machine.

Expected columns: Region, Warehouse, Outer Location, Bin, ASIN, Owner, Disposition, Amazon Device Flag, Quantity, Average Age, Average Threshold. Extra columns are kept on the line export.
