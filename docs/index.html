About

About this hub

This is a static site (hosted on GitHub Pages) that serves as the front door to my engineering work. The portfolio tracks what's shipping for leadership; the toolkit lets teammates self-serve the tools I build. The setup builder runs entirely in your browser — it never uploads anything and simply generates a script you run locally. Its catalog is shared with the Rig Setup app.
